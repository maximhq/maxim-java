This is JVM (written in Kotlin) SDK for enabling Maxim observability. [Maxim](https://www.getmaxim.ai?ref=npm) is an enterprise grade evaluation and observability platform.

## How to integrate

### Install

1. Gradle/Groovy
```groovy
implementation("dev.getmaxim.sdk:maxim-java:0.1.2")
```
2. Maven

```xml

<dependency>
    <groupId>ai.getmaxim.sdk</groupId>
    <artifactId>maxim-java</artifactId>
    <version>0.1.2</version>
</dependency>
```
